# Completed adjudication workbooks

These four files are exact copies of the completed v2.4.1 R_Bulun workbooks
supplied under the source project's top-level `human_adjudication/` directory.
The nested reviewer-run copies and other workflow versions are not included.

Use [results/index.csv](../results/index.csv) to locate the workbook and
`C_<paper_id>` worksheet for each of the 44 trial packages. Workbook paths in
that index are relative to `results/`.

All cell contents, notes, formulas, formatting, and embedded workbook links
are preserved. The copy does not rewrite Excel links to the original project
or test their behavior in Excel. The existing HTML reports keep their original
AI-stage findings and are not regenerated from these workbooks.

File hashes are recorded in [migration_manifest.csv](../migration_manifest.csv).
Checks cover byte identity, XLSX ZIP integrity, and the expected paper-sheet
names; they do not reassess the judgments or reproduce statistical analyses.
